# Serviette MCP server: tools, side effects, errors and limits

Documentation of the Serviette MCP server for Meta's Muse connector review (and for anyone connecting to it).

- **Endpoint:** `https://agent.withserviette.com/agent/mcp` (MCP over streamable HTTP, JSON-RPC)
- **Authentication:** none for everything except the two "my saved orders" tools. Those answer `HTTP 401` with a `WWW-Authenticate: Bearer … resource_metadata=… scope="orders"` challenge before they run, and the client signs the customer in with OAuth 2.1 (authorization code, **PKCE `S256`**, dynamic client registration, `resource` parameter, refresh tokens). The customer proves their email address with a six-digit code emailed to them. The only scope is `orders`.
- **Region and scope of service:** UK restaurants, collection only (no delivery).
- **Payment:** never through the connector. An order is a priced quote with a `pay_url`; the customer checks it and pays on Serviette's own page (cards by Stripe). No tool charges, spends or places an order.

## Classification

| Tool                     | Class                     | What it does and its side effects                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------ | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `list_cuisines`          | Read                      | The cuisine keys restaurants are described with.                                                                                                                                                                                                                                                                                                                                               |
| `find_restaurants`       | Read                      | Restaurants near a UK postcode or location, or by restaurant name (`brand`): the closest site of each with the first collection time. Neutral list, no ranking.                                                                                                                                                                                                                                |
| `get_restaurant`         | Read                      | One restaurant and its sites: address, opening hours, ways to order.                                                                                                                                                                                                                                                                                                                           |
| `get_menu`               | Read                      | A site's collection menu: item and modifier ids, prices (minor units and formatted), dietary flags, allergens, `age_restricted`.                                                                                                                                                                                                                                                               |
| `get_availability`       | Read                      | The times an order can be collected at a site.                                                                                                                                                                                                                                                                                                                                                 |
| `get_order_status`       | Read                      | Whether a quote has been paid, expired or is waiting. `wait_seconds` (up to 20) holds the call open until it is paid; it changes nothing.                                                                                                                                                                                                                                                      |
| `list_my_saved_orders`   | Read (needs sign-in)      | The signed-in customer's saved orders. Never returns another customer's.                                                                                                                                                                                                                                                                                                                       |
| `create_order_quote`     | **Write**                 | Checks and prices an order against the live menu, and returns a `pay_url`. It creates a quote that expires after 30 minutes and holds nothing: **no order exists and nothing is charged until the customer pays on the page**. Safeguards: at most 20 quotes per restaurant per hour from one client, a maximum order value and an orders-per-hour limit set by each restaurant, fraud checks. |
| `reorder_my_saved_order` | **Write** (needs sign-in) | The same for one of the customer's saved orders: a new quote at today's prices and times.                                                                                                                                                                                                                                                                                                      |
| `save_order`             | **Write**                 | After an order is paid, and only if the customer says yes: keeps it for "order again" and emails the customer a link (one email, to the address that paid). The customer can delete it from its page.                                                                                                                                                                                          |

**Sensitive writes:** none. We classify `create_order_quote` and `reorder_my_saved_order` as ordinary writes because they commit the customer to nothing: the customer sees the items, collection time and total, confirms allergen information, and pays on the payment page. We would like Meta's view on whether quoting a purchase should be treated as a sensitive write; it is simple for us to require approval each time if so.

Also available, off by default: `request_saved_orders_code`, `list_saved_orders` and `reorder_saved_order`, which find saved orders by an emailed code instead of OAuth.

## Errors

A failing tool returns a normal MCP result with `isError: true` and JSON text `{"error": {"code": "...", "message": "..."}}`; the message says what to do. Codes include: `invalid_postcode`, `invalid_cuisine`, `invalid_brand`, `location_required`, `radius_too_large`, `operator_not_found`, `site_not_found`, `channel_not_available`, `closed`, `asap_unavailable`, `invalid_time`, `empty_basket`, `invalid_item`, `invalid_modifiers`, `basket_too_large`, `order_too_large`, `site_busy`, `too_many_quotes`, `quote_not_found`, `quote_expired`, `payment_in_progress`, `not_paid`, `cannot_save`, `sign_in_required`, `saved_order_not_found`. A call to a tool that needs the customer, without a token, is `HTTP 401` (above). Text written by restaurants (names, descriptions, menu items, notes) is cleaned, and the server's instructions tell the assistant to treat it as data.

## Rate limits

Without a platform key, per client address: 60 read, 10 write and 120 MCP requests per minute. A platform with a key has higher limits (600, 60 and 1,200). Beyond a limit the answer is `HTTP 429` with `Retry-After`.

## Allergens and age-restricted items

Allergen and dietary information comes from the restaurants. The payment page asks the customer to confirm they have seen it. Items such as alcohol are marked `age_restricted`; the customer is told they may need to prove their age when they collect.
