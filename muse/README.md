# Serviette for Meta Muse

Muse connectors are submitted through a web form (muse.ai/platform), not a package. This folder holds what is needed for that form:

- `SUBMISSION.md`: the answers to paste, the checklist, and the risks to settle first.
- `TOOLS.md`: the documentation of the MCP server that Meta asks for (read/write classification, side effects, errors, limits).
- `icon.png` (512 × 512) and `icon.svg`: the connector icon.
